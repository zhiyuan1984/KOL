## 实现

Agent 展开区使用既有摘要来源；通用空摘要和重复任务名称不单独成行。技能/来源、创建时间、开始时间、优先级和截止时间只在字段存在时顺排。

业务任务显示 task.goal；目标与名称相同则省略。创建、优先级、截止和工单概况采用横排元数据。优先级沿用 taskPriorityLabel；未知编码显示原值，不推测含义。无标准工单只呈现“工单 无”，不再渲染标题加长空态文案。

有工单时渲染 32px 紧凑子表；无负责人用“未分派”，无决策用“—”。长标题和决策可通过 title 查看完整内容。长摘要溢出时显式提供“展开全文/收起全文”，不静默丢弃正文。
