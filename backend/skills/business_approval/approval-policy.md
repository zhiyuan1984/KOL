# 费用档与汇率 — 检索协议

本文件**不是**汇率表，也**不是**档位金额的唯一真相。
改档、改汇率：改这份说明（检索词、可信源、政策公布页）。**不要改 TypeScript 常数。**

数字必须来自你（Codex）**本轮**用内置 **网络搜索技能**（`web_search` / `$web-search`）查到的、可引用的来源。
禁止用训练记忆、禁止用 Host `policy.ts` 里的 7.2 / FIN-EXP 表、禁止编造。

## 必须先搜索

在写出 `create_approval` 之前，对本轮币种和费用档各至少成功一次网络搜索。
不要裸 HTTP 爬虫；用 Codex 网络搜索技能。沙箱已为本技能打开网络。

## 汇率

检索顺序（写进搜索查询，带上申请日或当天日期）：

1. `中国人民银行 人民币汇率中间价 {币种} {YYYY-MM-DD}`
2. `国家外汇管理局 人民币汇率中间价 {币种}`
3. 央行官网或权威财经转载的**同一日**中间价（次优，必须标明）

采用规则：

- 优先：检索日当天、中国人民银行人民币汇率中间价
- 必须写下：源标题、URL、发布/摘录日期、`1 外币 = ? CNY`
- 人民币 / CNY / RMB：本位币，`rate = 1`，不必搜汇率，但费用档仍要搜
- 禁止：默认 7.2，或任何未出现在本轮搜索结果里的固定表

换算：`amount_cny = amount × 本轮搜到的 rate`（四舍五入到分）。在引用里说明算法。

## 费用档（政策）

档位阈值来自公司**已公布**的费用审批制度，不是 TypeScript，也不是模型记忆。

检索顺序：

1. 本文件「政策公布页」里的 URL（有则先打开/搜索该页）
2. 公司内网或知识库：`费用报销 审批权限 额度` / `营销费用 审批档`
3. 本轮 box 若注入了「组织与政策摘录」，以摘录及其来源 URL 为准

### 政策公布页（改档改这里，不改代码）

- 制度名称关键词：费用报销审批权限、营销费用、单笔广告费
- 公布页 URL：（待配置。运营把现行制度链接写在这一行）
- 文号 / 生效日：（待配置。有则写入，便于核对是否现行）

采用规则：

- 用搜索到的**现行有效**制度：政策名称、文号、生效日、档位原文摘录
- 按申请人职级 + 折合人民币金额，对上制度里的档
- `policy.id` 用制度原文里的条款号或档位编号；原文没有编号就用条款标题，不要发明 `FIN-EXP-00x`，除非本轮搜索/注入原文里出现该编号
- 禁止：使用记忆中的 5000 / 50000 / 200000 或 `FIN-EXP-004`，除非本轮搜索或公布页原文里写了

## 搜索失败

不要猜档，不要用 Host 常数补档。

- 汇率搜不到：`needs` 加入 `fx_source`，用用户语言说明「没有查到当天中间价，请提供汇率来源或改日再试」
- 政策搜不到：`needs` 加入 `policy_source`，说明「没有查到现行费用审批制度，请在技能说明里补上公布页」
- Host 在缺少出处时**不得**用本地常数替你补档或补汇率（演示 stub 除外）
