## 统计审计

- `/api/tasks/operations-dashboard` 与 `/api/tasks` 同源于当前授权的任务投影，周期使用上海时区；搜索、手动日期和类型同时发给两接口。
- 运营的六状态是周期全量的互斥分解；类型分析的“处理中（含等待）”包含等待，不能与“执行中”混称。
- 明细的状态计数是当前条件的**已载入集合**，不是运营全量；状态/逾期过滤在 Agent 服务端执行，游标仍用于继续载入。业务来源的本地状态计数也只代表已载入集合。
- 业务任务和子工单是独立对象，不与 Agent 总量相加冒充同一指标；手动 Agent 日期不改变子工单周期。
- 对用户提出的 28/39、14/25，以等量分页夹具复现并验证“已载入 / 接口总量”与继续读取入口。前序对话缺原始接口响应、账号和时间快照，**不能据此认定历史生产差值就是分页造成**；当前实现清晰区分这些范围，保留原始接口口径。

## 实施与回退原因

- Tasks 使用局部 Ant Design Table/Select/RangePicker/Segmented，主行 compact，表头固定、独立滚动；长字段留在展开层，详情/进度或结果/取消/展开/分页与筛选都保留。
- 复选框只表示可批量取消，使用后端显式 `cancelable` 或 `allowed_actions`。缺授权不默认允许；业务任务不可选。后端复用 native ticket command 的同一权限函数，不用旧生命周期状态猜权限；缓存按请求身份隔离。
- 单个/批量取消均保留确认和版本化命令。批量使用逐项回执，部分失败刷新并明确说明未确认成功，不自动重试不确定结果。
- `07532b4573` 添加独立 Agent 详情和若干紧凑覆盖；当前 styles.css 保留列宽/间距片段，但缺少 grid/flex 基础显示规则，布局依赖不完整。新增仅限详情根的完整样式，较高作用域优先级与路由 CSS chunk 同时保证直接打开、刷新和回访。
- `adac96d68c` 的业务 Drawer、事件登记确认、建议采纳、撤权、草稿、返回快照继续保留。共享组件不迁移独立地址。
- 详情保留原始内容/上下文/失败与等待原因；产物、业务事件和执行尝试可展开完整字段。异步读取有版本保护，拒绝访问清除旧详情。
- DESIGN 的 token 登记表有历史漂移；仅运行既有生成器同步事实表，不修改设计法条或 token 数值。

## 验证与发布界限

测试证据以本次实际命令结果为准：前后端类型、生产构建、任务域单测、权限与统计单测、任务运营/业务抽屉/独立详情浏览器回归。夹具 E2E 不代表真实业务写入或 Codex harness 验收。
独立 PostgreSQL API 集成依赖测试模板数据库；缺失时如实标记跳过，不使用生产库替代。
发布前确认远端版本及工作区；部署使用仓库门禁和提交绑定的 release.json，旧产物在 dist.prev。服务不健康或发布版本不匹配不得报告成功。
