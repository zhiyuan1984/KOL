## 0. 风格基准

`data-dense-dashboard` 的库定义：

| 项 | 值 |
|---|---|
| 关键词 | 多图表/控件、数据表、KPI 卡、**最小内边距**、网格布局、空间高效、最大信息可见度 |
| Best For | 运营看板、企业报表、BI、财务分析 |
| 效果 | 悬停提示、行悬停高亮、筛选平滑过渡、数据加载态 |
| 无障碍要求 | `contrast-text-4.5`、`keyboard`、`visible-focus`、`reduced-motion` |
| 库建议变量 | `--grid-gap: 8px`、`--card-pad: 12px`、`--row-h: 36px`、`--sidebar-w: 240px`、`--header-h: 56px` |

**本产品的取舍**（库建议 → 本项目）：

- 侧栏宽（`styles.css` 的 `--left-width`）：库建议 240，本项目**取 260**（已锁定的紧凑壳），折叠档 56。
- 行高节奏（`--row-h`）：设计值默认 36（库值）；紧凑档 32。**该 token 尚未在 `styles.css` 定义**，落点仍靠各页面的 `min-height` 字面值，属 §8 待新增。
- 整体气质：**安静白底、发丝分隔、克制排版、几何化控件**——即"研究笔记本"而不是"营销落地页"。
- **单色驱动**（§5.1）：页面以中性阶承担结构，品牌主色只出现在**每屏唯一一个实底 CTA** 与链接式动作的悬停上。
- **不采用**落地页结构（Hero / 功能卡墙 / 底部 CTA）：本项目是登录后的工作台，服务回头用户，不是说服访客。

## 2. 字体与字号

字体栈：`Inter, "PingFang SC", "Noto Sans SC", system-ui, sans-serif`。

| Token | size / line-height | weight | 用途 |
|---|---|---|---|
| `--ds-font-tag` | 11 / 16 | 500 | 角标、计数。**不得用于可点标签** |
| `--ds-font-helper` | 12 / 16 | 400 | 元信息、辅助说明、badge |
| `--ds-font-sm` | **13 / 20** | 400–500 | **主力**：可点标签、chip、表格、表单 |
| `--ds-font-body` | 14 / 20 | 400 | 控件文字 |
| `--ds-font-ui` | 15 / 24 | 400 | 正文界面（已锁定的壳） |
| `--ds-font-section` | 16 / 24 | 500 | 节标题 |
| `--ds-font-block-title` | 20 / 28 | 500 | 块标题 |

权重只许 **400 / 500 / 600**，禁 700 以上。

**硬规则**：控件必须显式写 `line-height`（`--lh-control: 20px` / `--lh-control-sm: 16px`）。不写就会继承根的 24px 行盒，出现"小字被胖药丸包住"。

> **与外部阶梯的差异（§5.1）**：shadcn 的字号阶梯是 `12/14/16/20/24/32`，本产品在 12 与 14 之间**保留 13px 标签档**。理由：密集工作台里 13px 是可点标签与表格单元格的主力（见规则 7 的 13px 下限），取消它会迫使标签在"太大"和"不可点"之间二选一。这是**有意偏离**，不是遗漏。

## 4. 圆角 / 间距 / 阴影 / 布局常数

**圆角**（按用途命名，不复用 `--radius-sm/md/lg` 旧名，避免与 `styles.css` 既有值混淆）：

| Token | 值 | 用途 |
|---|---|---|
| `--radius-control` | `6px` | **紧凑控件**：≤28px 高的按钮、图标砖、badge、TabsList 内的触发项 |
| `--radius-card` | `8px` | 卡片、成组容器外框（= shadcn 的 `--radius: 0.5rem`，即 `rounded-lg`） |
| `--radius-md` | `10px` | 面板内块 |
| `--radius-lg` | `12px` | 对话框、抽屉 |
| `--radius-pill` | `9999px` | **主 CTA** |

> **划分依据**：**胶囊只留给主 CTA**；**6px 给「紧凑控件与附着标记」**（按钮、触发项、图标砖、badge），使它们同排时几何一致；**8px 给「面」**（卡片、成组容器）。`--radius-card` 与 `--radius-control` 的 2px 差值不是随意取的，它等于 shadcn `rounded-lg` 与 `rounded-md` 之差（§5.1）。
>
> **「圆角随组件复杂度递增」**（参考素材 Olist 的 `radius progressivo por complexidade`，§5.2）：控件 6 < 面 8 < 面板块 10 < 浮层 12。层级越高、越"浮"的元素圆角越大。
>
> **例外**：Composer 保持已锁定的 22px。

> **命名漂移（登记，属 §8）：** `styles.css` 现有 `--radius-sm`、`--radius-cards`=14px、`--radius-inputs`=22px 是旧名旧值，与本表不一致。本表使用 `--radius-control` / `--radius-card` 新名，**不动旧 token**，避免影响其它页面。

**间距**（4 / 8 / 12 / 16 / 24 / 32，与外部阶梯同源）：`--space-1..5 = 4 / 8 / 12 / 16 / 24`。

**阴影**：内容面**零阴影**，靠 `--border` + 空白分界。只有两种：
`--shadow-quiet`（极小面积的状态提示，如 TabsList 的选中触发项）与
`--shadow-popover: 0 4px 12px rgba(0,0,0,.08), 0 1px 2px rgba(0,0,0,.06)`（深色 `0 4px 12px rgba(0,0,0,.4)`）。**`--shadow-popover` 尚未定义**，当前浮层各自写字面值，属 §8 待新增。

**布局常数**：侧栏 `--left-width: 260px` / 折叠 `56px` · 内容上限 `--content-max: 1200px` · 顶栏高 56px（**无 token**，属 §8 待新增 `--header-h`）。

## 5. 使用规则（违反即视为不合规）

1. **同一视口 0–1 个实底主 CTA。** 实底 = 用 `--primary` 填满。其余动作降为描边或幽灵。
2. **浅主色配方（历史上的 `--primary-tint`）只能用于选中 / 悬停**，不得当静止底、整列背景或图标砖底。该 token 已按规则 18 **退役**；本条保留为**取向约束**——将来若重新登记派生 token，其允许用途仍只有"选中"与"悬停"两类。
3. **主色当文字 / 图标时必须用 `--primary-text`，不得用 `--primary`。** `--primary` 在白底只有 4.87:1、在 `--ds-surface` 上 4.58:1，作为正文尺寸文字余量不足；`--primary-text` 实测 6.45 / 6.06:1。**全页扫描**：`[data-skill-catalog]` 内**任何元素**都不得把 `--primary` 算成 `color`（门禁已按此断言）。
4. **状态不能只靠颜色。** `--ds-surface` 与画布只有 1.06:1、`--surface-hover` 只有 1.22:1；选中行 / 选中卡必须另加 2–3px 左侧强调条、勾选标记**或**字重提升。
5. **每个控件显式设 `line-height`。**
6. **可操作控件边框必须用 `--control-border`（3.45:1）**，不得用 `--border`（1.16:1，只配做分隔线）。

   **裁定（UI/UX 专家，2026-09-21）：** 本条的「可操作控件」指**表单控件与按钮**——WCAG 1.4.11 意义上「需要视觉识别其边界与状态的用户界面组件」。**卡片 / 列表行 / 面板等容器**的静止态边框属**分隔线**，可用 `--border`；但容器的**可操作状态（`hover` / `focus-within` / `selected`）必须**用 `--control-border` 或 `--text` 表达，且容器内必须有至少一个真实控件（按钮或链接）承担可交互身份与焦点环。
   理由：把每张卡片都做成 3.45:1 描边会让密集网格整体变重，与 §0 的「最小内边距、最大信息可见度」冲突；容器内的真实控件已提供等效的可辨边界。

   **成组控件由容器承担边界（2026-09-21 补，§5.1 落地）：** 一组功能等价的筛选 / 切换控件放进同一个浅面容器（`.skill-tabs-list` = `--ds-surface` + `--radius-card` + 2px 内边距）时，**边界由容器的填色承担，触发器自身不再描边**——容器与触发器两侧同时画边会变成双框，反而更脏。此时本条对"每条边框"的要求降级为"**容器必须给出可见的面差**"，选中项另换回 `--bg` 并加 `--shadow-quiet` + 字重提升（非颜色信号，服从规则 4）。成组的判据是"同排、同型、互斥选中"；**不满足这个判据的并列控件仍必须各自描边。**
7. **字号下限 12px 且 11px 不得用于可点标签；可点标签一律 ≥13px。** 控件文字走 13 / 14。「查看全部」这类文字链接也在约束内——它同样是可点标签。
8. **带框按钮内不加装饰图标。** 但**链接式动作**与**图标按钮**必须带语义图标：用 SVG，不用 emoji 或文字符号当图标；图标按钮必须另有 `aria-label`（语义不能只靠图形象征）。
9. **表面分三级，不靠颜色分层：** `--bg`（画布）/ `--ds-surface`（极浅面，用于成组容器底与图标砖底）/ `--surface-hover`（悬停与选中底）。**灰要极浅**（判据：与白画布的对比度 ≤1.1:1，只用来区分面，不用来传达强调）。`--bg-elevated`(#F1F1F1) 为 1.13:1，**不得作静止面**。**输入框不做极浅面填色**（§5.1：shadcn 的 `Input` 是透明底 + 描边），避免"灰底 + 灰边"双重弱化。
10. **只标例外。** 默认态不标注；只有 L3（需确认）、异步作业、异常才打标记。**「只读」这类默认值不标**——满屏同款标签等于噪声，是页面变「脏」的主因之一。
11. **卡片元素上限：1 图标 + 1 标题 + 1 描述 + 1 组标记 + 1 个动作。** 来源、来源系统名、内部编号等元信息归详情列，不上卡片。
12. **tint / 派生色必须从 `--primary` 派生**：`color-mix(in srgb, var(--primary) N%, <bg>)`，**不得硬写色值**——这样 `--primary` 按 §8 迁移时派生色自动跟随，不会二次漂移。
13. **语义色允许且应当使用。** `--warning` / `--danger` / `--success` 用于风险档与状态；但必须「颜色 + 文字」并行（与规则 4 一致）。
14. **紧凑档（≤28px 高）的次动作按钮用 `--radius-control`**，不得用胶囊——24px 高的胶囊两端半圆会吃掉字。
15. **并列动作必须有可见边框；单一动作可以走链接式。** 容器内有**两个及以上**并列动作时，必须用带框按钮区分主次（层级靠字重与字色，不靠去掉边框）。容器内只有**一个**动作时，允许走**链接式**：无框 + 语义图标 + **常驻**下划线（不只在 hover 出现），以缩小占用。
16. **卡片上最多 1 个动作，且不得放「直接开新会话」类动作。** 部分技能需要先填参数，直接开会话是错误承诺（PROD-AGENT 入口契约）。需要开会话的场景应走详情列或 Composer。

> **动作定名（2026-09-21）：** 卡片与详情栏的同一个动作统一叫「**填入输入框**」。语义是「把技能填进输入框，补完参数后由员工自己发送」——**不等于**「发送」，**不等于**「开会话」，**不含执行**。用 `title` 补全语义：`title="把这项技能填进输入框，补完参数后由你发送"`。**不得**改成语义更重的词（如「立即执行」「运行」「一下跑完」），以免暗示已经执行。

17. **图标只有一个尺寸阶梯。** 只许 `--icon-sm`（14px，控件内）与 `--icon-md`（18px，标识砖内）两档；图标按钮的方形边长固定 `--icon-btn`（24px）。**禁止在页面里写裸像素值，禁止出现第三档。**
18. **颜色只有两个来源。** ① **中性阶**：只有下列角色，每角色**只许一个 token** —— 画布 `--bg` / 极浅面 `--ds-surface` / 悬停-选中面 `--surface-hover` / 分隔线 `--border` / 控件边框 `--control-border` / 弱化文字 `--text-muted` / 正文 `--text`。② **主色派生**：只许 `--primary`、`--primary-hover`、`--primary-text`。
    **禁止新增任何灰度 hex 或浅主色配方。** 现存 **4 套平行灰阶**（OpenAI-quiet / Design System v1 / 壳杂项 / 功能私有色板）与 **3 套浅主色配方**（`--color-pink-tint`、`--color-pink-tint-soft`、`--ds-selected-bg`）全部进 §8 迁移清单，不再用于新代码。

    > **`--primary-tint` / `--primary-tint-strong` 已退役（2026-09-21）。** 按 §5.1 的单色驱动取向，静止面、图标砖底、选中底一律走中性阶。技能目录页是首个落点：13 块浅粉图标砖、1 块浅粉选中卡、1 处主色强调条全部改中性。

19. **键盘焦点必须可见（focus-visible）。** 所有可操作元素（按钮、链接、输入、图标按钮、可点标题）在键盘聚焦时必须有 `2px` 实心环，环色取 `--focus-ring`，`outline-offset: 2px`；**鼠标点击不得出现这圈环**（用 `:focus-visible`，不用 `:focus`）。
    - 环用 `outline` 实现，**不参与布局**，因此不得用 `border` 或 `box-shadow` 代替——前者会推动布局，后者会被"内容面零阴影"（§4）的约束掩盖。
    - 输入类控件的环加在**承载边框的容器**上（如 `.skill-search-wrap:has(.skill-search:focus-visible)`），使环与边框同心，不在输入框内再套一圈。
    - **禁止 `outline: none` 后不给替代视觉**——这是 WCAG 2.2 AA「焦点可见」的直接违反。

> **反扩散的验收判据（可执行）：** 本页渲染出的**不重复计算色值 ≤ 20 种**，所有 SVG 的渲染宽度**只取 `--icon-sm` / `--icon-md` 两档**，且**没有任何元素把 `--primary` 当文字色**——见 `frontend/e2e/skills-catalog.spec.ts`。多一个灰、多一个粉、多一档图标尺寸、多一处主色文字，断言就会失败。**这才叫"有保障"：不靠人记得，靠门禁挡住。**

## 6. 设备适配

### 6.1 三轴分离（核心原则）

布局适配由**三个正交的轴**决定，**绝不允许合并成一个"设备名"断点**：

| 轴 | 媒体特性 | 决定什么 |
|---|---|---|
| **宽度** | `width` | 侧栏形态、内容列数、表格形态 |
| **高度** | `height` | 密度档（矮窗收紧节奏） |
| **输入模态** | `pointer` / `hover` | 命中区下限、hover 是否有意义 |

**为什么不能按设备名分支**：触摸笔记本（1366×768 + 触摸屏）应该拿**桌面布局 + 触摸命中区**；带键盘的 iPad 应该拿**平板布局 + 指针命中区**。UA 嗅探在这两种情况都会判错。**禁止用 UA 嗅探做布局分支。**

### 6.2 行为断点

| 档 | 触发 | 侧栏 | 内容列 | 密度 | `--hit-min` | 表格 |
|---|---|---|---|---|---|---|
| **S 单栏** | `width < 600px` | 全屏抽屉 | 1 | 宽松 | **44** | 卡片化 |
| **M 折叠** | `600–899px` | 56px 图标栏 | 1–2 | 中 | **44** | 横向滚动 |
| **L 紧凑** | `900–1279px` | 可折叠 56↔260 | 2 | **紧凑** | 40 | 横滚 + sticky 首列 |
| **XL 默认** | `1280–1599px` | 260 | 3 | **紧凑** | 32 | 全列 |
| **2XL 舒适** | `≥1600px` | 260 | 3–4 | 默认 | 28 | 全列 |

`--hit-min` 是默认值，被输入模态覆盖：

```css
@media (pointer: coarse) {
  :root { --hit-min: 44px; --touch-gap: 8px; }
}
```

矮窗单独触发密度收紧（与宽度无关）：

```css
@media (max-height: 900px) {
  :root { --row-h: 32px; --section-gap: 16px; }
}
```

### 6.3 密度两档的**可测**数值差异

| 项 | 紧凑（L / XL） | 默认（2XL） | 宽松（S / M，触摸） |
|---|---|---|---|
| 行高节奏（`--row-h`，待新增） | 32 | 36 | 44 |
| `--control-h` 控件高 | 28 | 28 | 32 |
| 卡片内边距 | 8 | 12 | 12 |
| 网格间距 | 8 | 12 | 12 |
| 区块间距 | 16 | 24 | 24 |
| 页面留白 | 16 | 24 | 12 |

### 6.4 绝不随断点变的不变量

- **颜色 token**（浅 / 深两套，与宽度无关）
- **字号阶梯** `--ds-font-*` 全部不变
- **圆角**（§4 的 6 / 8 / 10 / 12）
- **层级与信息顺序**
- **无障碍要求**：对比度、焦点可见、状态不只靠颜色

理由：**同一产品在不同设备上必须是同一产品。** 允许变的只有：间距、行高、侧栏形态、列数、命中区。

### 6.5 禁止

- 禁止 `transform: scale()` / `zoom` 假装密度。
- 禁止 UA 嗅探做布局分支。
- 禁止在断点里改字号或颜色。
- 禁止整页横向滚动（只有表格、代码块、长 token 可局部横滚）。
- 禁止内容宽度撑满视口（必须受 `--content-max` 约束）。

### 6.6 数据表的窄屏规则

1. **列少**：直接展示。
2. **列多**：`overflow-x: auto` + `sticky` 表头 + `sticky` **首列（身份列）**。
3. **极窄（S）**：降为卡片列表——每行一张卡，字段纵向排列。
4. 禁止把列压到不可读；挤压不是适配。

### 6.7 固定栏与焦点

侧栏 / 顶栏 / Composer 固定时，用 `scroll-padding-top` / `scroll-padding-bottom` 让键盘焦点不被遮挡（WCAG 2.2 AA 2.4.11）。这与"页面只保留一个主滚动容器"并列执行。

### 6.8 文本与长 token

- 中文长标题必须能正常折行；**不得用 `white-space: nowrap` 硬撑**。
- URL、稳定 ID、邮箱等长 token 允许 `word-break: break-all` 或横向滚动，并保留可访问的完整值路径。
- chip / tag 集合应换行或使用可操作的 `+n` 展开；**不得把标签截断到只剩两三个字**。
- 数字列右对齐并使用等宽数字（`font-variant-numeric: tabular-nums`）。
