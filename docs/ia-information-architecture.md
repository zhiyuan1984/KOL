## 1. 一页一问

每个表面只回答一个问题。不得把另一表面的信息架构、主 CTA 或导航职责抄过来。

| 表面 | 只回答 | 禁止混入 |
|---|---|---|
| **Home** | 现在做什么。平台模式：今日任务、我的待办。KOL 试点另挂 AI发现、我跟进的红人 | 正式 Pipeline 资产板、Admin 治理、第二套会话开工台 |
| **Chat** | 完成一件具体任务并产出可确认结果 | 全局运营看板、后台配置、把 Pipeline 当第二会话启动器 |
| **Pipeline** | 管理已进入正式生命周期的合作资产、阶段与推进（**KOL 试点页**） | Home 四模式、待办桶、探索式搜索、Admin 授权矩阵 |
| **Admin** | 谁能用、用到哪、连到哪、是否发布、审计能否回放 | 员工日常任务、业务流水线操作、再做一套 Home / Pipeline / Agents 开工台 |
| **一等能力面** | 各答本面自己的问题（§2）；与任务队列、数字员工解耦 | 复制 Home / Chat / Pipeline / Admin 的 IA；降成 Agent 设置或任务 Tab；把「支撑」读成二等 |

「支撑能力面」只表示**不得复制**上表四核的 IA，也不得做成第二套 Home（ADR-015）。不是二等，不是 KOL Agent 附属 Tab，也不因「有没有进行中任务」才存在。

## 2. 十六项一等能力与 KOL 试点特化

权威清单是宪法 §4.1。本表只写 **IA 坐落**：哪个问题、落在哪条路径、是不是默认导航。未实现或占位**不降等**。

| # | 能力面 | 只回答 | IA 坐落 | 默认导航 |
|---|---|---|---|---|
| 1 | 任务/会话 | 现在做什么 / 完成这一件 | Home「今日任务 / 我的待办」+ Chat | 是（平台脊柱） |
| 2 | 数字员工 | 找谁协作 / 召唤岗位专家 | 员工 `/agents` | 是（文案「数字员工」） |
| 3 | 数字团队 | 预留；尚未实现 | **无表面** | **禁止假导航**（见 §4） |
| 4 | 技能 | 用哪项已授权能力推进当前工作 | 独立一等入口（若露出） | **UX 密度**，不是「员工永远不许看见」；禁止图鉴压过任务脊柱 |
| 5 | 知识库 | 查找 / 理解适用 / 预览 / 收藏 / 用于当前任务 | 员工 `/kb` | 可；治理（发布/停用/版本/范围）只在 Admin |
| 6 | 连接器 | 我已被授权可用哪些（使用/状态，不是配置） | 员工 `/connectors` | 可（使用面）；治理只在 `/admin/connectors` |
| 7 | 审批 | 哪些单要我确认 | 员工 `/approvals`；确认队列也可在 Home | 可；不是第二套 Home |
| 8 | 人员与权限 | 谁能用、用到哪 | Admin | 管理端 |
| 9 | 审计/Trace | 变更与调用能否回放 | Admin | 管理端 |
| 10 | 考试 | 员工应试 | 员工 `/exam` | 可；闸门治理在 Admin |
| 11 | 项目 | 占位可 | 未实现不降等 | 明示占位，禁止假完成 |
| 12 | 云盘 | 占位可 | 未实现不降等 | 明示占位，禁止假完成 |
| 13 | 手机遥控电脑 | 占位可 | 未实现不降等 | 明示占位，禁止假完成 |
| 14 | 定时/自动化 | 今天或按点要跑什么 | `/cron` | 可；不得做成第二套 Home |
| 15 | 通知/收件箱 | 要我看的通知 | 未要求本轮实现 | 未要求本轮实现 |
| 16 | 个人设置 | 个人绑定与偏好 | Settings | 是 |

KOL 是**首个业务试点**，不是平台壳（宪法 §4.2）。下列对象不是中台脊柱，后续试点不得把它们写成平台唯一 IA：

- Home 内「AI发现」「我跟进的红人」
- Pipeline（正式合作生命周期资产板）
- KOL / Collaboration / CreatorCandidate 等试点对象

平台任务/会话脊柱仍是 Home「今日任务 / 我的待办」+ Chat。

## 3. 使用 ≠ 治理

同一业务对象可以有**配套**的使用面和治理面；禁止做成**副本**（同一 IA、同一 chrome、同一开工 CTA）。

| | 使用面（员工） | 治理面（Admin） |
|---|---|---|
| 只回答 | 现在做什么、如何完成这一件、我已被授权可用什么 | 谁能用、用到哪、连到哪、是否发布、考试是否挡住、审计能否回放 |
| 连接器 | `/connectors`：已授权条目的业务标签与诚实状态；绑定 CTA 只去 Settings | `/admin/connectors` 枢纽 + `/:id`：启用、凭据引用、授权矩阵、组织策略 |
| 数字员工 | `/agents`：召唤已发布岗位专家（只建绑定，不发信、不写阶段） | `/admin/agents`：发布 / 可写范围 / 考试闸门 / 连接器授权 |
| 知识库 | `/kb`：查找 / 预览 / 收藏 / 用于当前任务 | 发布 / 停用 / 版本 / 范围 |
| 个人绑定 | Settings（例如 Starry 发件箱） | 组织策略在连接器详情，不再挂一份个人绑定表 |

配套细则、枢纽字段、遗留收敛仍以 [`org-permissions.md`](org-permissions.md) 为准。本文件只锁 IA 原则：员工默认路径不得深链 Admin 治理；管理端顶栏不得跳员工开工入口充当治理页。

## 4. 导航密度

侧栏是工作入口，不是能力图鉴，也不是试点资产目录。

| 必须 | 禁止 |
|---|---|
| 平台工作入口：Home / 进行中、`/agents`（「数字员工」）、知识、审批、考试、Settings | 发明可见组标题（「今日 / 智能体 / 资产」）；簇间只用分割线，`<nav aria-label>` 留给读屏 |
| 资产簇只含知识库 / 审批 / 考试 / 可选连接器使用面 / **明示占位** | 员工默认项深链 `/admin/connectors` 或任何治理页 |
| Pipeline **页**仍存在（深链或产品内 CTA 可达） | 把 Pipeline / 「生命周期」做成**必挂侧栏**；把 Pipeline 做成第二套 Home |
| 技能若露出，必须是独立一等入口 | 把技能图鉴塞进数字员工簇，或做成连接器治理入口 |
| 「数字团队」保留产品名词（宪法 §4.1 #3） | **专家团假导航**、把未实现的数字团队做成冒名入口、把该名词写成永久禁词 |
| 确认队列在 Home（结果待确认 / 等审批） | 再做一条克隆审批的「等我确认」顶栏 |
| 员工进管理端：仅账户芯片菜单「管理控制台」→ `/admin`（需 admin） | 主路径砖、SkillHub 调试砖、Agents 卡链进 Admin |
| 占位能力（项目 / 云盘 / 遥控等）须标明未实现 | 用占位入口假装已完成或已接通 |

技能侧栏露出 = UX 密度，不是「员工永远不许看见技能」。仍禁止能力图鉴压过任务脊柱（ADR-023）。

## 5. Home 四模式（只点名）

宪法 §4.2 已锁定名称，本文件**只复述，不立法微 IA**，不恢复排序键、四带教条或字段黑名单：

```text
今日任务 | 我的待办 | AI发现 | 我跟进的红人
```

前两项是平台任务脊柱；后两项是 KOL 试点挂件。「我跟进的红人」是 Collaboration 跟进面，不是第二套 Pipeline 正式资产板。
