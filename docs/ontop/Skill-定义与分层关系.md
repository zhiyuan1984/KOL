# Skill：定义与分层关系

> 整理时间：2026-10-01
> 本篇是《企业智能体与本体论研究笔记》的拆分文件之一，聚焦"Skill"。相关文件：本体六构件、任务、智能体、知识库。

---

## 1. 定义

**Skill 是打包好的"手艺包"**——完成某一类工作所需的 know-how，通常包含：

- **怎么做**：操作指令和流程；
- **用什么工具**：调用哪几个动作、按什么顺序；
- **好坏样例**：示例、质量标准和常见错误。

## 2. 实例：「催收 skill」

先读客户对象看逾期全貌 → 按规则算风险等级 → 高风险选强硬话术、低风险选温和话术 → 调用"发送催款函"动作 → 3 天无回款自动跟进。

## 3. "Skill 是不是最简单的智能体？"

**严格来说不是。** Skill 自己通常不感知环境、不自主规划、不维持任务循环，它是被调用的。

类比：**Skill = 菜谱 + 专用厨具，Agent = 厨师**。

但最简单的智能体 ≈ 一个模型 + 一个 skill + 一个任务/反馈循环，所以 skill 是组成智能体的**最小"能力原子"**。

## 4. Skill 在五层架构中的位置

| 层 | 回答的问题 | 实例 |
|---|---|---|
| 本体层 | 世界是什么样——"是什么"的知识 | 客户A的逾期金额、风险等级 |
| 动作层 | 受治理的单个操作原语——"能干什么" | 发送催款函、冻结客户 |
| **Skill 层** | 完成一类任务的方法论包——"怎么做事"的手艺 | 催收 skill、补货 skill、审批 skill |
| Agent 层 | 模型 + 若干 skill + 记忆 + 目标——"干活的人" | 催收智能体 |
| 调度层 | 任务来了，匹配 skill，派给合适的 agent——"派活的工头" | 逾期事件 → 催收任务 → 装备催收 skill 的 agent |

## 5. Skill 与其他概念的四组区分

- **Skill vs 动作**：动作是原子操作，skill 是编排动作的 know-how。
- **Skill vs 任务**：任务是"要干的一件活"，skill 是"干这类活的本事"。**调度的核心匹配逻辑：任务 → 所需 skill → 装备该 skill 的 agent。**
- **Skill vs 本体**：本体是陈述性知识（世界长什么样），skill 是程序性知识（事情怎么做）。对应语义记忆 vs 程序记忆。
- **Skill vs 事件**：很多 skill 是事件驱动的——**事件是扳机，skill 是弹药**。

## 6. 企业价值

Skill 是企业把顶尖员工 know-how **资产化**的容器：有版本号、有质量评估、有使用统计，是企业 AI 能力复利增长的地方。

- 模型会换代；
- 本体是地基；
- **skill 库是企业的"武功秘籍库"**——竞争对手抄不走的那层。
