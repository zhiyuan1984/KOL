基线为已上线的 GitHub main `59cbce57`。先保存阶段7压缩摘要，再执行本阶段。范围限定为一条已实现邮件技能交接链、当前上下文、来源失效恢复及两项受影响的现有任务/工单用例；不验收32个技能，不建设新的关系引擎，不增加设备矩阵。

## 发现与修复

真实运行先生成了邮件查询结果，但进一步核对Worker持久日志发现缺少交接来源。原因是Host的 `runWorkerFlow` 重新组装输入时，漏传了已由 `resolveBoundTask` 校验任务归属、会话和运行关系的 `work_item_id` / `task_run_id`。这使Worker无法执行交接来源版本复核，不能把初次结果当作交接验收成功。

本阶段仅在该投影中补上两个已校验引用，沿用服务器绑定和原运行器校验；不接受调用者自报权限，也不重写任务执行或邮件解析。阶段7正式合作、交接页面、原审批链及技能正文不变。
