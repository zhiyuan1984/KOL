# 产品咨询与非结构化资料接入

## 审查记录

需求：管理端保存 PDF 草稿，配置产品咨询技能、产品专家 Agent，并赋予鄢棽使用资格。

主责角色：后端专家负责执行授权与检索，前端专家负责草稿与治理入口，测试经理负责本次修改的定向验证。

宪法条款：CONST-02/03/05/06/08/10。基本法：PROD-PLAT-04/05、PROD-AGENT-01/03/09、TECH-BE-01/04/08、TECH-TEST-01/03。

结论：符合。人员资格继续以 Agent 为锚点，知识查询通过已发布技能调用；PDF 草稿不产生索引、不发布。文档问答是 L1 只读资源工具；不开放管理员试算权限给员工。执行前与返回前复核资格及文档状态，原件访问独立复核当前权限，引用须属于本次文档范围。

现状差距：既有知识流水线与运行时仍使用旧同步数据库访问抽象；本次测试强制 PostgreSQL 隔离库，不新增 SQLite 路径，也不宣称已经完成 TECH-ARCH-01 的全仓原生驱动迁移。

## 实施与验证范围

- 草稿上传、独立解析、管理首页非结构化文档展示。
- 查询技能声明 `knowledge.ask_documents`，显式绑定非结构化库；依赖由同一技能的 Agent 共用。
- 技能运行身份从当前可用的 Agent 装配中解析，不让管理端创建的技能隐式依赖 KOL Agent。
- 仅已发布文档进入员工查询；待审核单文档仍由管理端试算。
- PageIndex 升级至 0.2.21，使用明确的本地 storage_path，原件页码映射和引用范围校验。
- 定向验证：知识文档后端用例、Agent 知识装配、产品咨询管理端 E2E、桥接存储隔离和 OCR 页码映射。真实引擎以合成 PDF 验证；实际产品 PDF 保留草稿，不以合成内容代替产品事实。

下一步：根据定向测试证据配置用户指定资产；文档发布必须作为后续独立治理动作。
