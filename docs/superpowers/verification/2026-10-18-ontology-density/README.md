# 本体中栏密度收口

用户确认计划后指令“干”：删除与我相关／全部范围，默认权限内全部；标签黑色、选项浅黑，标题／分类／对象名字号统一；进一步压缩分类和列表行高，更多／收起采用Ant Design图标。其余不改。

审宪：需求 → UI/UX与前端实施、测试经理验证 → CONST-04/08/10 → TECH-FE-02/03、TECH-TEST-02 → 符合；仅改变现有授权数据的默认展示与中栏视觉，不改授权、后端或数据库。右栏JSX逐字相同，旧CSS原样保留，中栏覆盖样式独立限定。下一步：按既有授权推送部署并只读核验版本健康。

实测：16项本体页面用例通过。标题／分类标签／选项／对象名13px；标签使用现有ink黑色，默认选项和对象名使用graphite浅黑色；分类控件24px，对象行28px（浏览器边界含线不超过29px），粗指针可点区域保留。DownOutlined／UpOutlined复用已安装版本，无新增依赖。保留三级同时展示、续行左侧、中栏单滚动、对象字段和操作。组织关系表与配置入口保留，页面不再用它裁剪默认目录。

证据区分：页面测试使用明确API fixture；截图由Codex以UI/UX专家Agent角色核对，不声称人类用户研究。无后端修改，因此不重复数据库测试。前端构建与线上版本、健康检查另有记录。
