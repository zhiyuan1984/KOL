## 语义与保护

渠道利润分析归财经，销售侧为引用；品牌/系统授权记录、制造/办公工位、设备/售后维修工单、客服/内部工单记录与升级分别标明语义。同名不等于同一对象。企业SKU归产品，Amazon Listing归销售；客户、供应商、应付账款按用户指定权威归属。

既有属性/事件/规则/动作保留；新类型未提供五维明细时保持空态。规划定义不是业务实例、不启动外部工具。员工只能读取目录说明，运行时权限仍以Agent和既有闸门决定。

PostgreSQL新增ontology_catalog_nodes/objects/placements/imports；保存来源哈希、原文行号、主归属及导入回执。导入为单事务、幂等、唯一主归属；不写ontology_documents/versions/confirmations/receipts、不覆盖任何租户草稿或业务实例。原始配置注册表不替换。
