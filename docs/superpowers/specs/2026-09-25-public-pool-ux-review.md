## 保留、改进与回滚

**保留**既有路由、`GET /api/home/pool` 的零写入读取契约、公开字段边界、L3 领取确认、领取后撤销入口，以及最多选择 8 人的限制。**改进**信息顺序为身份/当前公开状态、平台与在库信息、公开指标与入库时间、公开简介，以及右侧明确标注的「公海原因」；该原因复用后端已返回的公开状态，不读取或推断私有归属和往来字段。局部硬编码色值和不一致控件尺寸收敛到全局设计 token；搜索、更多操作和外链使用语义 SVG；批量操作明确作用于当前可见结果。空态的「立即同步红人库」现在显式调用 `POST /api/home/pool/sync`，只通过白名单的 Starry 只读档案接口更新本地公开档案索引，随后轮询同一路径的本地回执；远程 MCP 调用不再占住浏览器 HTTP 请求。该流程不创建会话、不调用模型、不读取联系方式，也不改远端档案。**移除**全选时覆盖隐藏选择、分析按钮对隐藏选择仍可提交的误操作风险，以及点击“同步”实际仅重试读取而不刷新索引的断链。最高风险是筛选前后的选择集合、同步失败的可见反馈和远端超时，因此增加了端到端与接口回归用例。回滚方式为还原本次提交；正式领取、阶段与远端业务数据均未变更。

## 2026-09-25 聚焦工作区补充

**模式**：Redesign · Preserve。**保留**左侧全局导航、`?tab=pool` 路由、搜索/筛选/排序字段、`data-*` 测试锚点、分析入队语义与领取的 L3 确认。**改进**公海从窄右栏提升为中栏的主工作面，删除不产生决策价值的空白引导区域；标题、筛选工具与行内容共享一个宽度轴，按“状态与身份 → 公开指标 → 公开简介 → 领取与原因”组织，便于在一屏内比较更多对象。领取仍是逐行显式动作，分析反馈则回到列表标题下方，避免在页面其他区域丢失。前端基于公开主页 URL（无 URL 时基于平台与显示名）折叠同一公开档案的遗留/远程重复 UID，优先保留公开字段更完整的记录；不合并、不读取也不推断私有业务数据。

## 2026-09-25 上传方案收敛

**模式**：Redesign · Preserve。依据上传的结构图和验收文本，将公海明确为高密度“线索挑选工作台”，而不是 KOL 详情卡片集合。**保留** `?tab=pool`、公开字段边界、Checkbox、搜索/筛选/排序、最多选择 8 人、分析入队、L3 领取确认、领取后的短时撤销及更多操作。**改进**读取顺序为“头像 → KOL 与状态 → 平台和在库 → 核心数据与入库时间 → 一行公开简介 → 领取/更多”；标题和工具栏统一到同一 32px 控件节奏，头像为 56px，列表行保持 112–126px。**移除**“公开对象池”眉题、领取说明占位、闲置状态的重复呈现，以及右侧重复的“公海原因”列：状态标签是唯一的公开状态/入海原因表达，灰色表示“未首次建联”，浅红表示“14天无回复”。蓝色仅用于可执行操作，红色仅用于超时状态。

| 项目 | 决策与护栏 |
|---|---|
| 受保护契约 | 路由、`data-*` 锚点、字段来源、分析入队、L3 领取与撤销均保持不变。 |
| 行内容 | 不新增、推断或展示私有归属/往来数据；14 天无回复的历史仍属于详情层。 |
| 交互反馈 | 领取后先显示“已领取”，650ms 后从列表移除；4 秒内可使用“撤销”，不使用成功大弹窗。 |
| 最高风险 | 删除重复原因列可能影响测试或辅助理解；以状态标签、`data-public-stage`、行高和控件尺寸回归覆盖。 |
| 回滚 | 还原本次前端提交；后端索引、领取记录及远端红人库均未修改。 |

## 2026-09-25 双栏工作台纠偏

**问题**：先前的聚焦布局把公海清单提升为全宽主区，挤掉了中栏的人机交互，并违背了参考图的“中栏 Agent 协作、右栏对象决策”信息架构。**纠正**：公海与“我的红人”重新共享同一个两栏工作台：中栏始终呈现选择状态、分析边界、运行反馈与底部提问框；右栏始终呈现公海对象、筛选、排序、批量分析与逐行领取。为避免旧的收起状态遮蔽修复后的右栏，公海栏的本地记忆 key 升级为 `ui:home-pool-rail-collapsed-v2`，首次进入默认展开。

右栏以参考图为准，行内顺序为“选择 → 头像 → 身份与状态 → 平台/在库 → 公开指标与入库时间 → 简介 → 领取 → 公海原因 → 更多”。“公海原因”是右栏扫描列，状态标签是身份行的快速识别；两者均只复用后端公开状态，不引入私有往来或归属数据。领取仍保持 L3 确认，批量分析仍只作用于当前可见选择。
