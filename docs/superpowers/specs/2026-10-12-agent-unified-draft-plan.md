## 审宪与责任

- 需求：简化资产首屏，将职责、技能/知识依赖、数字员工归属、使用绑定纳入同一份候选配置，统一检查和发布。
- 主责：平台产品经理定义生命周期；UI/UX 专家定义摘要和分组交互；后端专家负责候选配置、覆盖内核、并发和原子提交；前端专家负责状态与恢复；测试经理负责数据库与浏览器证据。

## 生效与兼容

旧内容草稿继续可读；缺少新增治理字段时保持当前归属与使用绑定，不自动清空。新增草稿明确保存归属目标、使用绑定集合、变更原因以及基线指纹。即时撤权或归属变化后，旧草稿必须重新读取依据；旧检查不能重用。发布时在同一事务应用能力与实际变化的归属/绑定，写入独立关系回执和统一发布记录；失败全部回滚。

资产首屏仅包含职责、当前版本、归属路径、技能/知识数量、人员覆盖、待发布修订及最近发布结果。完整能力、覆盖、历史与审计按需展开读取。草稿分组编辑，保存与提交检查共用同一份输入。检查默认展示名称/职责差异、技能新增/移除/升级、归属前后、绑定及覆盖增减；后台仍校验完整候选及相关依赖。没有实际变更时不发布空版本。

组织与人员主数据、共享知识正文、共享技能配置不在 Agent 草稿内复制或改写。知识配置经独立查询技能形成依赖；知识范围改变必须明确引用发布版本。

## 验收

保存任意配置分组不改变运行装配、归属或资格；仅归属/绑定变更可以形成草稿并发布；发布失败不出现部分更新；复用确认只返回原回执；组织、依赖、即时撤权或草稿修订使旧检查失效。资产首屏不加载完整审计。键盘、窄屏、短屏、触摸和脏输入退出保护均验证。
