# Agent 数字员工组织归属：目标与计划

状态：已实施，本地范围验收完成。用户已认可当前 Agent 浏览结构，并于 2026-10-12 授权实施截图中的三级部门筛选与独立主归属。生产版本与上线结果以实际部署回执为准；未配置真实 Agent 的部门归属，既有数据不自动猜填。

## 目标与页面结构

管理员能按组织层级找到数字员工，并在详情中看清所属公司、部门路径和岗位职责。保留当前中栏浏览、右栏治理的骨架。

| 截图知识筛选行 | Agent 页新增行 | 来源 |
|---|---|---|
| 业务族 | 一级部门 | 权威组织关系表中的一级组织单元 |
| 业务域 | 二级部门 | 真实父子关系中的二级组织单元 |
| 知识库 | 三级部门 | 真实父子关系中的三级组织单元 |

三行放在搜索下、现有发布状态/人员绑定/修订草稿筛选之前；共用知识页的紧凑筛选控件、选中线与条件计数。标签表示层级，选项显示真实中心、部门、小组名称，不以组织类型推断层级，不另建部门字典。

## 归属口径

- 推荐首期每个 Agent 设置一个主归属组织单元，表达它作为数字员工的岗位归属；允许落在任意一级，完整上级路径由组织表推导，不能为了三行齐全虚构节点。
- 归属部门回答“这个数字员工在哪个部门任职”；人员绑定回答“哪些真人有使用资格”。两个关系独立维护，归属变更不自动新增、撤销人员资格，也不修改技能装配或数据范围。
- 数字员工的岗位身份与 Agent 能力组合继续区分，不把 Agent 注册成真人登录账号或写入真人成员名单。
- 已有 Agent 在取得明确归属前显示“未设置组织归属”；不根据名称、技能、使用绑定或执行部门推断主归属。系统后台 Agent 保留既有系统身份，可明确标注平台后台用途；不为补齐部门而虚构人员身份。

## 当前基础与缺口

已有 `organization_units` 提供公司、父节点、层级、名称、状态和组织版本；`organization_memberships` 记录真人成员关系；`agent_bindings` 记录人员使用资格。当前 Agent 工作台已经读取组织单元供人员绑定选择，但 `managed_agents` 与工作台契约尚未提供独立的数字员工主归属。

需要增加 Agent→组织单元的独立归属关系，引用已有组织主数据。只存实际归属节点与必要的公司、版本、有效期和变更记录；上级名称及路径通过现有组织表生成，不复制三级部门字符串。具体迁移细节在实施时确定，不把现有使用绑定重解释成归属。

证据资产：`backend/migrations/022_organization_agent_bindings.sql`、`backend/src/runtime/managed-agents.ts`、`backend/src/agents/workspace.ts`、`shared/agent-workspace.ts`、`frontend/src/admin/agents/AgentBrowse.tsx`。

## 实施顺序

1. **关系与真实数据**：建立独立主归属关系及历史记录；明确归属节点、公司与组织版本的校验。迁移保留现有 Agent、发布版本、人员绑定与回执，未确认的老数据不自动填写。
2. **组织读模型**：服务端提供归属路径、三级部门选项和当前条件下的 Agent 计数；部门名称和父子关系来自同一份权威组织数据。归属关系的公司与部门必须一致，禁止跨公司拼接路径；请求仍按现行权限在服务端限定范围。
3. **页面接入**：中栏新增三级筛选，右栏“职责与身份”增加组织归属与完整路径，在修订区提供设置/调整入口。归属调整作为独立资产治理动作，确认时校验版本并记录操作者、前后部门和回执，不随能力草稿发布暗中调整人员资格。
4. **迁移与验收**：提供未设置归属的待管理列表，逐项配置有依据的归属；验证筛选计数、部门调动、归档节点、异常关系、读失败、版本冲突以及桌面、短屏、触摸和窄屏。完成真实数据库与生产画面对照后再标记发布完成。

## 筛选与计数契约

- 默认三级均为“全部”；选一级后仅展示其有效二级，选二级后仅展示其有效三级。切换上级清除失效的下级选择，不丢失搜索或其他筛选。
- 一级/二级/三级筛选包含本级直属以及真实下级归属的 Agent。上级直属的 Agent 不复制到各个子部门，保证按 Agent ID 去重。
- 生产组织表于实施核验时存在第四级“AI产品组”：保留真实更深层级的完整归属路径。三级筛选也包含该节点的真实后代；筛选区仍只呈现用户指定的三行，不虚构或截断组织。
- 每行部门计数保留搜索、发布状态、人员绑定、草稿及其他层级条件，只忽略自身筛选轴；使用完整授权结果，不用当前分页行数统计。
- “全部”包含未设置归属的 Agent，并提供明确的未设置归属入口；已归档或关系异常的归属保留可追溯说明与恢复入口，不自动迁移到其他部门。
- 部门多时提供搜索选择；零计数可以收起但有恢复入口，已选零值部门常驻。读取中和失败时不展示伪造零计数。
- 全局发布状态概览继续统计当前授权范围的全量 Agent，与部门筛选结果的口径分别说明。

## 验收标准

从权威组织表调整一个部门名称或上级关系，刷新后选项与路径同步更新；配置某个数字员工主归属后，它能从相应的一级、二级、三级路径找到，且只计一次。归属修改前后，原人员绑定及其有效资格不发生隐式变化；保存或调整失败保留输入和恢复入口。现有草稿、发布、启停和人员绑定回归通过，实际画面保持知识页基准。
