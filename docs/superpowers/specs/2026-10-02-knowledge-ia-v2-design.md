## 3. 目标结构

### 3.1 布局（两端一致；左栏保持现状）

```text
┌ 左栏：平台导航壳（保持现状：AdminConsole 壳 / Workbench 壳）──────────────────┐
│ ┌ 顶栏：页面标题 ＋ 动作区 ────────────────────────────────────────────────┐ │
│ │ 管理端：知识管理 ｜ 分类目录 · 上传文件 · 新建知识（0–1 实底主 CTA）        │ │
│ │ 员工端：知识库 ｜ 仅展示已发布说明                                        │ │
│ ├ 工作区 ────────────────────────────────────────────────────────────────┤ │
│ │ 中栏（列表，弹性）：检索区 → 快捷视图 tab → 数量/排序 → 双行列表           │ │
│ │ 右栏（详情 rail，360–820px/54%）：crumb → 标题 → 状态行 → 内容/属性/版本   │ │
│ │                                  → 动作区（按状态唯一主 CTA）             │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────────────────────────┘
```

- 0–1 实底主 CTA：顶栏「新建知识」在选中草稿/待审批时让位（草稿→「提交审批」；待审批→「前往审批」）；弹窗打开时背景主按钮降级、关闭后恢复；原生 `<dialog>`＋焦点归还。
- 断点：≤1100 列表/详情上下堆叠（列表默认 6 条＋展开）；≤860 导航入抽屉；≤480 收紧；粗指针 ≥44px；外层不滚动。

| 原六项（v1） | v2 归位 |

- 管理端状态：**草稿 / 待审批 / 已发布 / 已停用**。设计稿「待审核」统一为「待审批」（与审批系统、既有文案一致）；「已归档」改文案为「**已停用**」（后端枚举 `archived` 不变；改名范围仅限知识域文案与相关测试，见 §8）。

## 4. 管理端设计明细

### 4.1 顶栏
- 标题「知识管理」；动作：分类目录（弹窗，管理态可新建/编辑，提示"合并/重命名需校验引用、保留历史分类标识"）、上传文件（次强调）、新建知识（实底主 CTA，按选中状态让位）。

### 4.2 中栏
- 检索：标题/主题/负责人搜索；领域/主题弹窗（层级＋搜索＋各层条目计数）；类型筛选；重置。
- 快捷视图 tab：全部 / 待审批 / 已发布 / 草稿 / 已停用（真实计数）。
- 列表两行：图标＋标题＋（路径 · 类型）＋（状态、责任人/日期）；选中左缘强调线；≤1100 折叠 6 条＋展开全部。
- 空态（管理端）：无数据/无匹配时给「上传文件 / 新建知识」双入口；员工端空态仅提示改筛选。

### 4.3 右栏详情
- 头部：crumb（族/域/主题）→ 标题（+员工端收藏）→ 状态徽标＋版本＋责任人·日期。
- tabs：**内容 / 属性与范围 / 版本记录**（员工端：**内容 / 来源与版本**）。
- 内容：管理端待审批时顶部提示条「此版本正在审批中 · 查看审批 →」；正文分节；「来源材料」行（文件上传→文件名；在线编辑→维护人）。
- 属性与范围（真实字段）：知识标识 KB-xxxx、领域/主题、适用范围（v1「发布即可见＋品牌/范围」，页面标注）、维护责任人、知识类型、内容模型/载体、来源、当前版本、复核/到期（映射真实 `expires_at`，无则不显示）。
- 版本记录：当前版本＋历史行；无真实历史时空态文案（不虚构记录）；后续批次补 diff/回滚。
- 动作区（按状态唯一主 CTA）：
  - 草稿：**提交审批**（主）｜修订、删除草稿（仅草稿，L3 确认）；
  - 待审批：**前往审批 ↗**（主，跳审批单）｜修订、更多；
  - 已发布：顶栏「新建知识」回归主位；本区 修订（次）、更多（调整适用范围 / 查看版本记录 / 停用已发布版本）；
  - 已停用：修订（复出新版本草稿，走审批）、更多。

### 4.4 弹窗清单
分类目录（选择态/管理态）、新建知识、修订知识、提交审批确认、上传文件（§5.1）、调整适用范围、停用确认、更多菜单。**审核弹窗退役**：发布决断迁入审批系统（§5.2）；原表单组件在审批页复用于决策界面（实施时复用，不复制逻辑）。

### 4.5 权限与确认（L2/L3）
- L2：保存草稿（标注「草稿」）；提交审批＝创建审批单进入审批链。
- L3：停用、删除（仅草稿）、范围调整 → 事实清单＋理由＋持久回执＋`expected_version` 409；发布由审批系统决定（同样是确认＋回执＋版本保护）。
- 权限校验在服务端（审批角色/知识域责任人）；前端不重写规则（CONST-04）。

## 5. 两条流程详细设计

### 5.1 多格式文件上传（管理端）

- **入口**：顶栏「上传文件」（次强调）；空态双入口之一；「新建知识」弹窗内切「文件上传」载体同一弹窗。
- **格式白名单**（accept 仅为提示，服务端复检）：
  - 文档：pdf / doc / docx / xls / xlsx / csv / ppt / pptx / txt / md / html
  - 图片：png / jpg / jpeg / webp（先 OCR/多模态）
  - **音视频：mp3 / m4a / wav / mp4 / mov / webm**（先转写稿＋摘要，接非结构化管线）
  - 文案标注分类：「音视频将先转写；扫描件将先 OCR」。
- **归档目标**：选择知识库（结构化/非结构化）；文件类型与库 kind 不匹配时给出建议并可切换（如 docx 邮件模板 → 结构化库提取占位符；pdf/音视频 → 非结构化库）。
- **逐文件真实状态**：待上传 → 上传中 → 排队 → 提取中/转写中 → 待核对 → 已生成草稿；失败可重试；详情内挂作业卡（进度、取消、重试；按 2026-10-02 非结构化规格）。未接后端阶段不得展示假进度（CONST-10）。
- **重复检测**：批内去重＋跨库同文件（hash）提示「已存在，仍要新建？」。
- **标题规则**：非结构化＋文件上传＝文件名（去扩展名）锁定；结构化＋文件＝自定义（提取字段人工核对后定稿）。
- **上限与错误**：大小/数量上限以后端为准（前端显示提示）；错误可见（格式不支持/空文件/超限/重复）。
- **提取衔接**：结构化文件沿用既有 raw→提取候选→人工校对链路；非结构化接 PageIndex 管线；提取未完成时提交审批按钮禁用并写明原因。

### 5.2 知识详情 → 审批（方案 B：接入平台审批系统）

- **提交侧**：草稿详情「提交审批」→ 校验（必填、分类、范围、来源、`expected_version`）→ 创建审批单（approvals；kind＝「知识发布」，命名待与审批模块对齐；payload/evidence：知识 id、被审版本、分类、适用范围、影响面、内容摘要）；知识进入待审批（绑定版本，防并发）。
- **审批侧**：审批单进入平台审批列表 `/approvals`（按审批链与角色）；审批人在 `/approvals/:id` 决策（通过/驳回＋意见）——复用既有审批确认与持久回执机制；`/admin/approvals` 保持「审批角色配置」职责不变。
- **回写**：通过 → 该版本 published＋记录审批人/时间；驳回 → 退回草稿＋意见入版本记录；审计沿用 `knowledge.*`＋审批审计；通知沿用现有通道（是否发企微卡待确认，空白①）。
- **知识页入口**：待审批详情＝提示条「此版本正在审批中 · 查看审批 →」＋动作区「**前往审批 ↗**」（主）；已处理＝「查看审批 ↗」；跳转携带审批单 id（可分享深链）。
- **一致性与保护**：发布决断**只在审批系统发生**（知识页不再就地发布，单一决策点）；`expected_version` 冲突 409；回执保留来源/版本/时间（CONST-06）。
- **能力边界（已核实）**：现有审批模块仅受理费用（`approvals.ts:79-95`）；方案 B 的泛化清单：① 受理 kind 扩展；② 非金额对象的链计算（审批角色按知识域责任人或通用链，`/admin/approvals` 已可配置角色）；③ 回写履行（沿用 `host/approval-fulfill.ts` 模式）；④ `/approvals` UI 对非金额对象的呈现适配。**P3 实施**；存量待审批条目过渡策略（一次性生成审批单或旧路径处理）实施时定。
- **员工端**：不出现审批入口。

### 5.3 员工端补回（本轮确认）

- 详情动作区：主 CTA「用于当前任务」；次动作「**反馈**」（三原因＋备注，沿用既有：内容过时 / 品牌用不上 / 发出去容易被拦；提交后进入管理端处置流）与「**隐藏**」（沿用既有个人隐藏语义，仅本账号生效）。
- 提示语保留「用于任务时引用此版本；不会自动发送或执行知识中的动作」。

### 5.4 相对 space-3 原型的修正（汇总）

| 原型 | 修正 |
|---|---|
| 「待审核 / 已停用」等文案 | 状态定稿：草稿/待审批/已发布/已停用（见 §3.4） |
| 详情内就地「审核」弹窗 | 发布决断迁入审批系统（§5.2），详情改为「前往审批 ↗」＋提示条 |
| 上传仅领域/主题、格式缺音视频 | 补目标库、音视频格式、逐文件状态、重复检测（§5.1） |

- 右栏：内容（使用范围提示条＋正文）/ 来源与版本；动作区：用于当前任务（唯一实底主 CTA）＋反馈/隐藏（§5.3）。

## 7. 视觉与无障碍
