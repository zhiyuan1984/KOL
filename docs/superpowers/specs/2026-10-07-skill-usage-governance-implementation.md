## 范围与证据

- 用户侧入口：`frontend/src/pages/SkillCatalog.tsx`；工作台草稿契约：`frontend/src/composer/types.ts`、`frontend/src/composer/draft.ts`、`frontend/src/components/ComposerDock.tsx`。
- 管理侧入口与编辑：`frontend/src/pages/SkillLifecycleV2.tsx`、`frontend/src/pages/SkillLifecycle.tsx`。
- 发布执行：`backend/src/routers/misc.ts`、`backend/src/host/skill-lifecycle.ts`。
- 视觉数值继续唯一取自 `docs/DESIGN.md`；本记录不新增 token 数值或业务规则。

## 发布边界

人工登记的验收结果不等于技能自动执行测试。技能草稿保存不改变员工使用的生效版本。发布仍由服务端按技能生命周期、知识依赖试算状态、调用权限与既有确认路径执行。人员使用资格仍由 Agent 绑定决定；本变更不新增技能人员授权。
