# Admin 页面覆盖规则

> 这是 Admin 重做时的目标行为简报，不认可或继承当前页面设计。Admin 只处理治理：谁可以做什么、能力如何配置、发生了什么。

## 边界

- 员工连接器页面用于查看可用能力和个人授权；Admin 连接器页面用于租户级配置、权限、健康状态和审计。
- Admin 不承载员工待办、创作者探索、Chat 任务或 Pipeline 日常推进。
- `/admin/connectors`、连接器详情、`/admin/agents` 与审计页面共享治理导航和术语。

## 布局

- 顶部显示治理对象、环境/租户上下文和一个主要管理动作。
- 列表优先展示状态、影响范围、负责人和最近变更。
- 详情按“概览—权限/配置—健康—审计”组织；危险区固定在末尾并与常规设置分隔。
- 配置表单按任务分组，低频高级字段折叠；不得一次呈现整份配置对象。

## 权限与审计

- 无权限时隐藏或禁用动作必须与权限策略一致，并说明申请路径。
- 权限变更、密钥轮换、停用、删除等动作展示影响对象与回滚能力，按风险进入 L2/L3。
- 审计记录显示操作者、时间、对象、动作和结果；技术详情按需展开。
- 密钥和敏感值默认遮蔽，解密/显示属于独立受控动作。

## 视觉

沿用 MASTER token 和密度。状态表格可更紧凑，但正文和关键说明不小于 14px；不要用后台模板的卡片墙取代清晰的列表与详情层级。

## 交互状态矩阵

| 元素 | Default / Hover | Focus / Selected | Loading / Disabled / Error |
|---|---|---|---|
| 治理导航 | 当前对象和层级清楚 | 深层详情保留返回路径；三级以上可使用面包屑 | 无权限页面说明可见范围和申请路径 |
| 权限矩阵 | 单元格同时显示主体、范围和状态 | 不能只靠单击小图标；键盘可切换并读出状态 | 保存中锁定冲突项；部分失败逐项显示 |
| 敏感值 | 默认遮蔽 | “显示/隐藏”按钮具有可访问名称和 pressed 状态 | 解密属于独立受控动作；失败不清空审计上下文 |
| 危险区 | 与常规设置分隔 | Dialog 默认焦点落在取消或安全动作 | 停用、删除、轮换均防重复，并显示持久审计回执 |

配置提交错误在字段附近显示；多字段错误同时提供可聚焦、可跳转的错误摘要。浏览器返回恢复列表筛选和滚动位置。
