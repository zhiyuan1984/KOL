# Home 页面覆盖规则

> 这是 Home 重做时的目标行为简报，不是当前页面设计说明。除已落地 token 外，不继承现有页面的布局和组件造型。业务事实与验收以对应 FS/UX 为准。员工交互范式是助理优先（ADR-032）：用户说意图 → 助理组织对象 → 优先卡 / 折叠分组 → 下一步。这不是「第二套会话」，也不是「列表为主 + AI 叠加」。

## 职责

Home 回答“我现在要做什么”，默认进入“今日任务”。平台模式：今日任务、我的待办。KOL 试点另挂：AI 发现、已关注创作者（不是平台一等清单）。模式切换保留用户当前上下文，不伪装成 Pipeline 阶段。

「Home ≠ Chat」只禁止再做一套带独立任务脊柱的完整 Chat 工作台。某一模式的问题由助理回答时，该模式可以使用助理线程 UX（会话脊柱 + 结果卡 + Composer 作页控件）。

## 布局

- 首屏优先显示当前模式、任务状态和一个主动作。同一视口只许 **0–1** 个实底主 CTA；实底走 MASTER `--primary`（产品粉红 + 白字，ADR-031 修订），不是 ~~Obsidian 黑~~。
- 今日任务以真实状态分组，等待项说明等待对象和恢复入口。该模式也可以是助理结果，只要仍答「现在做什么」，且不做成耐久待办状态桶导航。
- 我的待办强调责任人、截止时间和完成条件。
- AI 发现由 Composer/搜索条件、渐进披露的条件芯片和 CreatorCandidate 内容流组成；结果区是主要视觉重量，操作 chrome 保持稀疏。
- **我跟进的红人 = 助理脊柱 + 对象卡。** 仍答对象管理（我在跟哪些对象、对象事实是什么、能对对象做什么），不要求做成 ERP 列表。典型结构：助理话语 → 一次回答内的情境分区（如优先跟进 / 等待 / 拒绝，可折叠）→ 嵌入对象卡 → 底部 Composer 作页控件。字体走 Inter（OpenAI Sans 待许可）。色板映射 MASTER：正文近黑（Obsidian 只作文色 / 发丝源），画布 Paper，主填充 `--primary`。
- 准备回复 / 起草 = **L2 草稿**（须标明草稿/暂存，不外发、不写阶段）。阶段进入 = **L3**（对象 / 范围 / 后果 → 确认 → 执行 → 持久回执）。SEND≠STAGE。起草弱于阶段进入。
- 跟进面同一时刻只保留一个实底主 CTA。行内「准备回复」「查看互动」默认幽灵 / 描边。需要阶段写入时，唯一实底打开既有 L3 ConfirmStage（逐项或明确的多项确认）。空闲可以为 0 实底。

## 跟进面仍禁止

- 责任桶 / 待办状态桶 / owner tabs 作耐久主 IA。
- 15 正式阶段条带或 Pipeline 板作跟进面主筛。
- 助理话语自动写入 `stage_code`。
- 同一视口多个实底主 CTA。
- 只用颜色表达状态（绿徽章当唯一状态）。
- 未定义的「处理」在无 L3 时写入 `REJECTED`。

情境分区（优先跟进 / 等待 / 拒绝）只许出现在**一次助理回答内**，不是耐久导航 Tab，也不在本文件立法芯片文案或筛选项清单。

## AI 发现筛选

- 默认只显示当前条件芯片（平台 / 地区 / 方向）和「＋ 添加条件」。
- 平台：YouTube / Instagram / Facebook。地区为单选；方向为多选，最多 8 项。完整芯片行放在「添加条件」面板。
- 粉丝 / 均播 / 匹配度门槛与「按条件加入跟进」折叠在「高级筛选」。
- 显式 Chip 选择覆盖自然语言中冲突的同类条件，并显示可见的覆盖结果。
- 重置筛选不清空用户的自然语言目标。
- 结果区同一时刻只保留一个实底主 CTA（有选中时的「按所选加入跟进」）。行操作为星标、更多、安静「＋ 跟进」。

## 创作者结果与关注

- CreatorCandidate 显示真实来源、匹配理由和当前可用身份信息。
- 缺少真实主体 ID 时不得创建 Collaboration；界面应说明仍需验证什么。
- “关注”是 L3 确认动作。成功后进入已关注集合，但不暗示已发送、已暂存或已进入 Pipeline。
- 同一创作者在发现与已关注模式中使用一致的信息层级；跟进面用对象卡嵌在助理回答里，发现面用内容流，不要发明第三套卡片语言。

## 状态与响应式

- 空状态区分“尚未搜索”“筛选无结果”“服务不可用”。
- 检索失败保留输入与筛选，并提供重试；不得只显示底层 HTTP 文案。
- 窄屏将筛选放入抽屉，模式导航可横向滚动，但页面主体不得横向溢出。Composer 保持页控件，不另开第二套会话台。

## 交互状态矩阵

| 元素 | Default / Hover | Focus / Selected | Loading / Disabled / Error |
|---|---|---|---|
| 模式 Tab | 文字按钮；hover 只改变背景或文字强调 | 焦点环完整可见；选中同时提供底色、文字和 `aria-selected` | 加载不锁死模式切换；不可用时说明原因 |
| 筛选 Chip | 原生按钮；hover 不改变尺寸 | `aria-pressed` 与视觉选中同步 | 请求中仍可检查条件；禁用项说明约束 |
| 搜索/生成 / Composer | 主动作清晰；空闲 0–1 实底 | Enter 可提交，焦点不被结果更新抢走 | 使用稳定占位和忙碌状态；错误保留输入、筛选和重试 |
| 准备回复 | 幽灵 / 描边；标明草稿 | 填入 Composer，不写阶段 | L2；失败保留原文 |
| 阶段进入 | 需要时才出现唯一实底 `--primary` | L3 Dialog 内焦点受控，关闭后返回触发按钮 | 执行中防重复提交；成功留下持久回执；部分成功逐项说明 |
| 关注 | 显示真实对象与当前状态 | L3 Dialog 内焦点受控，关闭后返回触发按钮 | 执行中防重复提交；成功留下持久回执；部分成功逐项说明 |

模式与筛选应进入 URL，以支持刷新、分享和浏览器返回。横向模式导航支持方向键和键盘滚动，并提供可见的溢出提示。
