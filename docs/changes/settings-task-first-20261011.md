# 个人设置：任务优先改版（2026-10-11）

## 目标和范围
降低认知负荷，删除重复/无关信息与内部实现暴露；不是压缩字号或增加每屏信息。只改个人设置六类及公共导航相关噪音，必要服务端边界同步修复；不调整KOL业务阶段、审批制度、Agent资格和正式发信政策。

## 实现
- 六类：个人资料、账号与邮箱、工作偏好、账户安全、记忆、隐私与数据。兼容旧 `tab=profile/starry/preferences/security/memories/privacy`，URL刷新/返回保留。
- 分类按需读取；局部加载、失败、重试、真实空列表、未保存、保存中与结果分别呈现。React受控Ant Design Form在异步加载后设置真实值；失败保留输入；正式偏好只在成功响应后应用。
- 不再渲染handle/Git版本、管理员调试、Markdown实现术语和三项无可执行任务的占位导航；有效业务导航不变。
- 资料由本人最小化上下文加载；企业档案不自助编辑姓名/登录联系方式；组织资料按需展开，保留完整四级路径，直属上级只用明确manager关系，不把部门负责人当直属。
- 品牌稳定ID/品牌码按注册表适配，服务端合法范围与PEP交叉校验；邮箱无权威品牌则待核验，不根据域名猜测。
- 默认品牌用于新发现任务预填，不是授权。默认邮箱明确称“默认跟进邮箱”，与绑定 `is_default` 协调；不是发信许可。保存、到期、撤权重新复核。显式清除/解除后不选择另一项；登录态和首页默认查询也不回退到第一项。
- 原有正式发信PEP和确认不变；本轮不声称实现新的发送凭据校验或全站安全重构。
- 记忆列表+按需抽屉；本人对话最小化列表；版本/操作回执折叠，异常就地显示。
- 回执按账号及可选真实公司命名空间，分类隔离；旧无归属键拒读不迁移，登出仅清前端回执，审计不删除。
- 浏览器离开/返回/侧栏导航与刷新有未保存保护；危险操作取消默认焦点，不调用写接口。

## 规则缺口与保守处置
旧 `scope=team` 没有公司或组织范围，也在worker全量读取。为避免把该字符串当授权，本轮仅本人读取/消费，暂不允许新team发布或private→team转换；已存team数据不删除，作者仍可编辑、停用、删除。生产只读核查当前team行数为0，因此未取消真实已存在团队共享记录。后续团队共享需要业务负责人明确范围及持久化关系后独立实现，不能由同部门猜测。

企业登录别名自助验证未有工作流，本轮企业账号字段由管理员维护，不伪装成已验证。不会修改任何账号角色、访问授权或凭据。

## 验证策略
真实PostgreSQL临时库测试与浏览器模拟契约测试分别记录。浏览器模拟可以证明界面和错误路径，不代替生产权限/外部服务验收。生产验收只读，不为证明功能而发送邮件、改密码或删除真实数据。

布局覆盖375/768/1280/1920视口；表单单列左对齐，正常宽度主按钮，Tabs横向溢出菜单保留完整分类；复用现行设计token。典型任务定位时间、主观易用性评分和20%提速目标尚未有真实用户实验，不宣称已达到。

## 发布与回滚
独立分支通过类型/单元/隔离数据库/相关浏览器回归后，使用现有发布流程构建新资产、原子替换，再同步重启Host/Outbox/Workers；记录版本与生产只读证据。无数据库schema迁移，无人员/授权/凭据数据批量修改。保留前版提交与前端dist；视觉回滚不得重新开放团队全量读取或错误原文下发等已收紧边界。出现相关权限或错误副作用失败不发布。
