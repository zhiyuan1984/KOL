# Admin Agents 页面布局迁移记录

- **页面 / 路由：** `/home/ubuntu/kol-global-impl/frontend/src/pages/AdminAgents.tsx` · `/admin/agents`
- **范围：** 仅调整展示结构；未改路由、API 请求、字段名、校验、确认、风险文案、发布/停用/撤销/绑定流程、权限判断、阶段或数据。
- **样式：** 未新建 `global-layout-agents.css`。本页已可通过共享 `InformationLayout` 的语义 token 获得属性列、24px 标签—值列间距与 13px 基准文字，避免新增页面特例。

## 最小迁移

1. **Agent 摘要**改为 `RecordRow`：名称、发布状态和“修改名称 + 发布/启用/停用”动作进入同一行；职责和可跳转指标保留在 `detail` 层。
2. **短属性**改为 `PropertyList`：职责、绑定影响试算、版本/创建时间/更新时间均使用统一左标签—右值模式（`labelWidth="short"`）。空职责仍明确显示“暂无职责说明”，不以破折号掩盖语义。
3. **绑定点**改为 `RecordRow` + `ActionGroup`：绑定对象与撤销动作同一行；长对象名使用 `TruncatableText`，保留键盘/触发式完整文本查看路径。
4. **短编辑字段**改为 `HorizontalForm`：知识库调用技能选择器、创建 Agent 的“Agent 名称”使用横向标签和值；创建窗口的“描述”显式保留为多行编辑例外（`ui-field-stacked`）。原受控状态、焦点引用和创建时校验未动。
5. **绑定预览操作**改为 `ActionGroup`；保留原有确认绑定/取消、影响人数、组织版本、人员增减名单与真实失败反馈。

## 已合规并保留

- 页面**没有数据表格**；未将任何现有表格或列结构改成 div 列表。
- 技能与知识库清单保留复选、推荐/失败提示、分页及保存状态；它们包含名称、摘要、推荐原因等多层内容，不强行压成单行。
- 覆盖名单按来源分组、组织级联筛选、候选目标多选、绑定试算与新增覆盖明细均维持原业务结构。
- 所有现有 `error` / `role="alert"`、状态回执、确认弹窗、未保存切换确认、禁用态和服务端组织版本展示均保留。

## 允许多行的例外

- Agent 职责、技能摘要/推荐理由、知识库说明、覆盖来源、绑定试算中的新增/移除名单：这些是解释性或异常/影响详情，放在详情层而非挤入标准记录行。
- 新建 Agent 的“描述”：长正文输入，采用标签上方/编辑区下方的显式多行表单例外。
- 组织人员绑定中的公司/三级部门级联筛选及候选目标多选：复杂条件组，保留原流式布局，不牵强改成短字段表单。
