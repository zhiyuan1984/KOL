## 设计决定

- 模式：Redesign · Overhaul（仅通讯视觉），保护邮箱/会话/邮件与任务深链、权限、发信/阶段独立确认、工作台保留。
- 视觉：Gmail 紧凑邮件工作区，不冒充 Gmail 品牌，不复制第三方插件按钮。
- 五档：视觉变化7、动效1、信息密度9、资产依赖3、业务契约保留10。
- 浅灰蓝底、白色阅读面、浅蓝笔形写信入口、灰色空心/暖黄实心收藏星、标签形图标与轻量色标。
- 现有字体、13px主文字/12px辅助文字、4px间距阶梯；邮件专用圆角与控件尺寸登记DESIGN，不影响其他页面。
- 原输入＋四按钮移除；仅一个复用ComposerDock的完整提问区，任务建议折叠在组件内部，明确发送后才执行。写信状态将同一编辑区切为邮件草稿，不出现第二份提问输入。
- 读取不启动AI、不创建Agent会话；标签候选必须来源于真实授权harness，采纳才保存，禁止手写名称和默认自动保存。
