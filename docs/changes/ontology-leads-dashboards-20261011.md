## 治理门禁生效边界

这是本体发布治理能力的首次安装。首次无发布账本时，本次用户已明确授权的补丁安装记录 `bootstrap=true`、`approval_not_claimed=true`；**不声称 CEO 已批准**，也不生成伪造审批记录。只有部署健康恢复后才写入首个四范围 PG 治理基线。

此后每次注册表内容变更，必须匹配 PG 中真实 `consumed` 审批的 scope、base_version、target_digest；发布账本存在后不能回落首装分支。PG 不可用、基线不完整、当前实际文件与账本不符均拒绝。账本由数据库触发器拒绝 UPDATE / DELETE / TRUNCATE。

本体审批并非任意 Git 写入限制：标准部署入口校验发布资产；对服务器拥有 root / DBA 权限的人仍可改变程序或数据库，属于特权运维边界，不冒充物理不可绕过。
