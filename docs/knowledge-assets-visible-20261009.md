# 知识资产可见改版（2026-10-09）

## 需求与审查

需求 → 用户指出截图没有变化，并明确确认中栏筛选/列表与右栏知识资产统计两块都要改。

主责 → UI/UX 专家、前端专家、测试经理；发布协调由项目经理承担。

条款 → CONST-04/06/08/09/10；TECH-FE-01/03、TECH-TEST-01/02/03/04；DESIGN §1、§8、§9.2、§28/28.1。

结论 → 符合。在既有 data-dense-dashboard 视觉系统内做 Redesign · Preserve，不改业务审批、权限、对象身份、阶段字典、服务端统计口径或路由职责。

## 设计决策

- 系统：延续产品品牌、13px/12px 字阶、既有蓝色辅助态、灰色信息背景、现有间距与圆角 token，不引入新品牌色、字体、图片或依赖。
- 密度：高密度；视觉变化低、动效低、品牌保真高。保留桌面列表/详情双栏与 36px 知识行。
- 中栏分类：默认仅显示有计数的分类和已选分类；空分类通过明确的展开/收起入口访问，保留真实 ID，不删除主数据。加载/读取失败不把未知计数当成零。
- 筛选范围：说明分类计数随其他条件变化；生命周期筛选是当前条件下的分布，全局资产条标明当前组织/全局，避免“全部 6”与“全局 13”被读成数据错误。
- 知识列表：增加紧凑列头，长文件名保留尾部用于辨认，不把所有非结构化资料都标成 PDF；类型筛选提供服务端已有的 document 轴。保留整行打开、全选/批量操作、同名独立 ID、右栏来源/版本/动作。
- 右栏资产：保留最近 main 已新增的健康队列；默认收起零计数分类、按真实计数降序展示、有明确组织范围说明；分布占比按该级真实 facet.all，不把组内最大值当总量。

## 受保护契约

保留知识规划、知识创作、知识加工、发布审批、知识资产五项导航，旧深链、查询参数、审批确认、未保存阻断和数据权限不变。零计数分类可以显示和选择；筛选导致当前已选分类为零仍保留。未知数据不渲染伪造 0。

发布基于最新 main，原工作区和线上并行补丁不覆盖；保存测试、生产截图及回滚证据后才报告完成。
