# 知识页面整合发布（2026-10-09）

## 授权范围与审查

需求 → 合并并发布知识规划、自动编码、文件列表与资料详情、创作区布局。

主责角色 → 前端专家、后端专家、测试经理；发布协调由项目经理承担。

宪法条款 → CONST-04（职责）、CONST-05（授权与正式动作）、CONST-06（原始事实）、CONST-08（审查）、CONST-09（规范层级）、CONST-10（可验证交付）。

基本法条款 → TECH-FE-01/03、TECH-BE-01/02/03/08、TECH-TEST-01/02/03/04。

结论 → 符合。本次只整合用户明确确认的知识页面工作，不修改业务阶段、人员授权、审批规则或发布副作用。其他正在进行的发现、任务、连接器修改不纳入本次提交。

## 实施资产

- 知识规划：Ant Design Collapse 提供多分支展开，节点选择与展开独立，保留搜索祖先链、原有详情深链和危险操作确认。移除重复标题和全量展开按钮，新建业务族入口放在列表底部。
- 自动编码：新建业务族、业务域、知识库不要求手填编码；后端生成唯一编码并在同一事务记录审计。现有显式编码调用保持兼容。无效父级、已归档父级、重复编码、并发冲突仍由服务端拒绝。
- 文件列表：紧凑双列“文件名 / 资料详情”，完整文件名在展开区可读；Ant Design Descriptions 展示文件名、分类路径、类型/大小和更新时间。原文件与加工审批入口保留。
- 同名资料：只按稳定 ID 去重，同名不代表同一文件或版本关系。显示同名独立记录，不自动合并。
- 创作区：上传文件、新建知识、查看草稿保持紧凑单行；切换不改变右栏生命周期，不重置中栏已选条件。
- 测试维护：旧八项导航断言对齐已发布的五项导航规范（DESIGN §28.1），仍验证被隐藏能力的独立深链。管理端内部留白按 §28 的 --space-5 检查，不错误要求与员工页内部留白完全相同。PostgreSQL 清理等待连接关闭，不再 FORCE 终止尚在关闭的连接；业务断言未放宽。

## 证据边界

前端单元、浏览器 HTTP 夹具和真实临时 PostgreSQL 集成测试分别记录，不能相互替代。真实 PostgreSQL 测试只创建随机临时库，不使用生产 DATABASE_URL；生产部署不执行 schema 迁移，也不创建知识内容、不外发、不推进审批。

部署采用独立目录，保留原开发工作区和已有线上补丁，记录主分支提交与保留差异，并在新版本就绪失败时恢复旧服务路径。具体测试数量、版本和线上健康回执写入本轮发布结果。
