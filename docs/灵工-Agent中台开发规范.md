## 一、规范核心总则

1. **功能底线**：完整保留现有业务功能、Agent 能力、资产体系。只做架构梳理、权限收敛、UI/UX 标准化，不删减原有业务逻辑。
2. **架构核心**：严格区分「管理端（资产管控）」「员工端（业务使用）」。资产统一管控，业务按需使用。智能体**模板–实例**正式数据模型为 P2；本轮用「已发布 Skill = 模板，session = 实例」。
3. **权限特殊规则**：超级用户 = 现网 `admin`（鄢棽），**两端可进**。可开调试视图。**不能**跳过确认发送、确认阶段、商务审批、PEP。
4. **UI/UX 基准**：对齐豆包 B 端；全局两栏（导航 + 主区），会话页可三栏。主色语义（蓝主操作、橙高危、绿成功、红错误）保留；具体 hex 不作为本轮验收。
5. **阶段写入口径（人确认无相邻约束）**：`legalTargets` 是人工确认列表，列出主流程 / 分支流程 / 异常流程，可跳过、纠正、进异常。不得以「仅相邻合法边」约束产品需求或人确认。物流 / 平台等自动事实写入另走 `autoLegalTargets`，不能替人跳过或纠正。跳过 / 纠正 / 异常必须填原因。

## 二、角色与两端权限（强制）

### 2.1 角色

| 角色 | 现网 | 权限 |
|---|---|---|
| **超级用户** | `admin`（可同时带 `employee`） | 登录管理端 + 员工端；资产配置；显式打开调试视图。高危动作仍要人确认。 |
| **普通员工** | `employee` | 只登录员工端；触发已发布 Skill；确认高危操作。无资产编辑、无模板配置、无调试视图。 |

不设「只能管不能用」的第三角色（避免把当前管理员锁出员工端）。若以后要普通管理员，另开需求。

### 2.2 管理端（唯一资产管控入口）

独占：知识库公共资产、Skill 发布与授权、连接器、密钥、角色、审计、全局风控。  
公共知识可走草稿–发布；Skill 本轮用 `in_market` + catalog + 测试，完整「草稿–测试–发布–回滚」为 P2。

### 2.3 员工端（唯一业务使用入口）

- 可使用**已发布** Skill，生成任务、跟进、确认发送 / 确认阶段。
- 禁止编辑、修改、删除公共资产。
- **彻底隐藏**：连接器配置、Skill 创建/管理、调度引擎入口、MCP / Codex / 线程术语、Skill 时序树。
- 个人私有知识库为 P2；本轮引用已发布知识，上传公共库走管理端。

## 三、智能体与资产

1. **Codex app-server** 在后台跑业务 turn（选 Skill、调 MCP、出结果）。Host 只跑会话 HTTP、PEP、确认发送 / 确认阶段。员工**可以触发已发布业务 Skill**，但看不到、也不能进入调度引擎。
2. 高危（对外发信、改正式阶段、解密联系方式、外部提交）必须有**运行时卡点**：弹窗，或会话内 L3 确认块，或明确口令「确认发送」。禁止只靠 SKILL.md 静态文字。管理员同样不能跳过。
3. 连接器只在管理端配置。员工端无感（不出现连接器菜单、MCP 名称、密钥）。
4. Skill 分 L1 只读 / L2 草稿 / L3 人确认写，映射编码规范闸门。高危 Skill 须管理员审核后 `in_market`。

---

## 四、视图规范

1. **全员默认业务使用者视图**：屏蔽 MCP、调度、线程、Codex、Host 等引擎词；只展示业务内容（阶段、SOP、邮件预览、待办）。
2. **调试视图仅超级用户显式打开**（默认关）。打开后才显示 Skill 时序、远程执行面、原始错误详情。
3. 阶段轨道、本阶段 SOP、邮件草稿是**业务结果**，不是调试信息，员工端保留。

---

## 五、视觉与布局（可量化，本轮不换肤）

1. 主色语义：蓝 = 主操作，橙 = 高危，绿 = 成功 / 已发布，红 = 错误。hex（如 `#1677ff`）不卡验收。
2. 全局两栏：左导航目标 240px（现网 `clamp(208px, 15vw, 240px)` 可保留），主区统一内边距。
3. 会话页：中栏业务工作区；右栏业务结果（阶段 / SOP / 草稿）员工可见；Skill 时序仅调试视图。
4. 必备：高危橙色确认、空状态、骨架屏、业务友好报错。员工端禁止堆栈。
5. 弱化纯聊天，强化任务驱动。

---

## 六、验收

1. 功能零丢失。
2. 权限零越界：普通员工不能进管理端、不能改公共资产；超级用户两端可进，但不能跳过确认闸门。
3. 视图零混乱：业务视图无技术术语；调试视图仅管理员打开后可见。
4. 风控零漏洞：发信 / 改阶段 / 解密均有运行时确认 + 审计。
5. 生产业务 Skill 走 Codex app-server；Host stub / 直出不算员工端 UX 验收。
6. 视觉换肤、Agent 模板表、资产三态回滚、个人私有库：**P2，不挡本轮**。

---

## 七、与编码规范的用词

对外统一 **管理端 / 员工端**。编码规范里旧称「用户端」一律视为员工端。
