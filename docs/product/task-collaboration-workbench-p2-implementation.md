已实现：

- 新增原生 PostgreSQL 邮件修订与错配隔离表；邮箱 + provider ID 去重，正文同长度修改仍产生新指纹，拒绝已知旧来源版本。发生时间缺失的首次邮件隔离，不伪造为当前时间。
- L1 按会话所有者、当前有效账号/品牌与绑定邮箱取数；返回来源核验时间、原文、稳定 ID、版本、持久事件游标。源失败、200 封窗口截断保持显式；查询不启动同步或模型。
- 现有 Codex harness 的回复分析和回复写信输入固定授权快照，输出记录版本与引用 ID。生成中相关依据变化标过期，撤权不发布结果；未启动第二个模型循环。真实模型完整正文影响分析尚未验收。
- 中栏每 15 秒读取本地授权快照，支持显式核验、变化提示及原文查看。读取不抢编辑焦点、不替换人工正文；右栏支持已保存稿与人工修改对比，回复分析时保留先前草稿与当前会话内未保存编辑。
- 发送预检绑定相关邮件及合作阶段版本，在统一网关和 sendEmailNow 适配器边界再次复核。空回复依赖也记录，首封来信可以使旧确认失效。明确未调用发送接口的拒绝保留草稿与原尝试审计，允许新确认；未知或已发送尝试不清除、不盲重发。
