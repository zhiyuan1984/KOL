## 字段方案

`followers_evidence` 包含：原文 `raw_text`（最多256字符）、`source_field`（专用 `subscriberCountText` 或 DOM 回退）、UTC 读取时间、解析版本 `youtube-subscribers/v1`、状态。

- `source_recorded`：专用订阅数字段或明确订阅标签可解析，采集来源已保留；不是正式档案或独立人工核验。
- `unavailable`：来源本轮不可解析，数值保持未知。明确的未知刷新清除采集器同一条记录中的旧数字，避免新原文和旧数字错配。
- `missing_source`：历史记录或不完整证据；保留原采集值供排查，模型的可用粉丝数为 null，页面不据此判定门槛。

账号数字、视频数、隐藏订阅数、多个冲突标签、畸形小数不作为粉丝数。裸数字只接受专用订阅数字段，不从页面混合文本提取裸数字。解析和原文保留使用相同的256字符输入，避免原文截断后无法解释数值。

MediaCrawler 的频道 client → core → 标准 writer → 已有 task-scoped loader → 本平台候选快照 → 模型上下文/页面，全程保留同一份来源。工具参数 schema 不变，既有任务文件不重写。原始 candidate 的旧数值4只保留为 `reported_followers`，不能进入模型的门槛判定。
