# 独立任务详情重构实施记录

## 范围与审查

本轮针对 `/tasks/:taskId` 独立详情，以及从任务明细进入和返回的导航链路。用户授权按既定目标实施，不修改业务阶段、权限模型、正式写入协议或任务运营统计口径。主责为前端工程与视觉设计；按宪法 CONST-08 审查、[技术规范](TECHNOLOGY.md)、[设计规范](DESIGN.md) §1、§4–9、§24、§29 和 [信息架构](ia-information-architecture.md) 的深链保留约定执行。结论为在现有权限边界内符合。

## 已实现

| 原问题 | 实施结果 |
|---|---|
| 返回只到任务中心页顶，不回明细上下文 | 返回 URL 带明细锚点，可靠来源下恢复搜索、来源、状态、时间与周期参数、已加载范围、滚动和原行焦点；原行不在结果时明确提示且不擅自清空筛选 |
| 业务对象显示为 Agent/manual | 按权威 `task_type` 或已注册模板元数据选择模型；业务聚合独立读取，未知类型中性展示 |
| 大面积留白、字段重复、技术信息占首屏 | 紧凑标题及唯一根状态；目标、推进、动作优先；真实事件和工单次之；原始字段合并进一处技术追溯 |
| 空模块挤占阅读流 | 成功返回且为空的模块收起；错误与受限仍明确显示，不能伪装为“无数据” |
| 关联模块 403 导致错误清空或反复挂载 | 独立验证主任务权限；主任务可读时保留正文，不反复重挂载；真正撤权时清除旧正文 |
| 独立页后退取消丢草稿 | 使用现有路由的阻断能力；取消后退保留组件和实际表单值；兼容旧 BrowserRouter，但不迁移全局入口 |
| 提交区离开视口 | 登记展开时固定提交区；短屏、窄屏及原生 200% 浏览器缩放仍可达 |
| 时区和原始时间混淆 | 展示使用业务时区，原始 ISO 值保留；手工时间注明浏览器本地时区，确认预览展示实际将提交的时间 |

抽屉与独立页共用主题和业务正文。Agent 任务继续保留真实执行事件、结果产物、已有会话入口；未运行和未知类型不伪造“Agent 已执行”。业务根状态不由子工单终态推断。

## 实施资产

核心资产为独立页、作用域绑定的导航快照、离开保护及路由阻断器、共享 Ant Design 主题、业务详情正文和局部样式。任务中心仅接入导航恢复、可访问焦点落点和业务状态文字；保留最新任务运营、任务查询和分页实现。未修改主入口、后端、Worker、数据库或任何账号权限。

## 发布与回滚方式

发布基线必须重新核验实际服务目录，不能使用之前失效的发布路径。仅覆盖本轮已审核的前端文件，逐文件检查部署前 hash；先备份源文件和 HTML 入口，再构建到临时目录并校验产物。新增带 hash 资源与旧资源并存，最后原子切换 HTML 入口。不重启后端和 Worker，也不覆盖其并行改动。

回滚恢复备份的源文件及旧 HTML 入口；新静态资源保留以避免已经打开的新标签页损坏。实际发布目录、备份位置、公网资源标记和线上只读验收结论在执行后补入。
