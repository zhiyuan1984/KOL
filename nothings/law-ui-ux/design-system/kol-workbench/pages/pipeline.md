# Pipeline 页面覆盖规则

> 这是 **KOL 试点** Pipeline 页重做时的目标行为简报（表面职责见 `CONSTITUTION.md` §4.2），不认可或继承当前页面设计。本页不是中台壳，也不是员工侧栏主入口（深链 / CTA 可达）。Pipeline 管理已进入正式生命周期的合作资产和阶段推进。

## 职责与结构

- 顶部显示 Pipeline 范围、关键统计和一个主要新增/导入动作。
- 筛选区围绕阶段、负责人、风险和更新时间；不得复制 Home 的模式导航或 AI 发现入口。
- 主区使用表格、看板或主从列表呈现正式资产，选择形式由任务密度决定。
- 详情展示主体、当前阶段、责任人、最近证据、阻塞和下一项合法动作。

## 阶段与动作

- 阶段是业务状态，不是纯视觉标签；颜色必须配合文字。
- 推进动作展示前置条件、目标阶段和影响范围。
- 批量推进必须显示选中数量，混合状态对象要分别说明可执行与不可执行原因。
- 导入、删除或不可逆阶段变更按 L3 确认；草稿型编辑按 L2 标记。

## 信息密度

- 关键列默认可见，低频字段进入列设置或详情。
- 表格行高遵循桌面密集控件基线，不通过小于 14px 的文字压缩信息。
- 长列表使用分页或虚拟化；只允许数据区域的受控横向滚动。

## 状态

空状态区分无正式资产、筛选无结果和权限不足。刷新或推进失败保留选择和筛选，并显示可重试范围。

## 交互状态矩阵

| 元素 | Default / Hover | Focus / Selected | Loading / Disabled / Error |
|---|---|---|---|
| 筛选 | 常驻标签，hover 不改变布局 | 条件写入 URL；焦点顺序与视觉顺序一致 | 加载保留当前条件；错误允许重试或撤销最近条件 |
| 数据行 | hover 只增强可扫描性 | 行选择同时显示复选框、数量和程序化选中状态 | 刷新时避免整表跳动；无权限动作说明原因 |
| 批量操作 | 未选择时不冒充主动作 | 工具栏出现后不遮挡表头或焦点 | 显示可执行/不可执行数量；部分成功逐项回执 |
| 阶段推进 | 显示当前与目标阶段 | L3 确认可键盘完成 | 执行中防重复；失败保留选择和前后 diff |

宽表放入带可访问名称的专用横向滚动容器；键盘用户能够到达并滚动。长 ID、URL 和用户文本必须安全换行或截断并提供完整值。
